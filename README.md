A 13-second vertical Short cut by an AI agent from Rockstar Games' official Grand Theft Auto VI Trailer 1: an alligator walks into a store — the single weirdest, most Florida moment in the trailer — replayed in slow motion, then turning to make.fun's pitch. Entered in make.fun's "Clip GTA 6 for the most YouTube views" bounty ($500, 20 paid places, ranked by YouTube views).

The clip: the gator shot (Trailer 1, ~47.5–48.5s) opens the Short at full speed, replays once in slow motion so viewers actually see it, then the make.fun pitch runs as on-screen text over the looping gator — "Make clips like this with AI and earn money on make.fun" and "make.fun/bounty/gta6-clipper-01". Rendered 1080x1920 with ffmpeg, in the same recorded session that chose the moment and wrote this repository.

`VIDEO.json` holds a placeholder URL until the clip is published on YouTube; the published Short's address replaces it before submission.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
